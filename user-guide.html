Multi-Tiered Node Architecture

02 // DATA STANDARDS

9-Digit Alphanumeric ID Formatting

All nodes within the system strictly adhere to a standardized structural formula to maintain interoperability across international registries:

[3-City / Locality Code] + [2-Nation Code] + [1-Function Flag] + [3-Sequence Number]

For example, `THRINC000` designates the Master Origin Node, where `THR` is Thrissur, `IN` represents India, `C` defines the function, and `000` marks the root sequence.
